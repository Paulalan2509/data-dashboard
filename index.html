About this project

This is a portfolio project by Paul Alain Nyoum. The sales shown are generated sample data for an imaginary café (90 days, fixed random seed), not real figures. Every chart is drawn by hand in SVG with no chart library, has a table view, and responds to the same filters so the numbers always agree.

Try your own data: upload a CSV with the columns date (YYYY-MM-DD), item, qty, unit_price, and optionally category and hour (0 to 23). Your file is read in your browser and never uploaded anywhere.

Built with HTML, CSS and vanilla JavaScript. No tracking, no libraries. Paul Alain Nyoum
